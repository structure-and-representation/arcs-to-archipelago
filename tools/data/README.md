# tools/data — 人口移動データの生成と検証

アプリが読み込む `public/data/od.json` を、総務省統計局の公表データから作るためのスクリプトです。データを更新する人はこの文書だけで作業できます。

## 取得元

総務省統計局「住民基本台帳人口移動報告」の長期時系列表 第11表
「移動前の住所地別転入者数及び移動後の住所地別転出者数－都道府県，3大都市圏，大都市(平成24年～)」

- 一覧ページ: <https://www.e-stat.go.jp/stat-search/files?toukei=00200523&tstat=000000070001&cycle=0&tclass1=000001051218&layout=datalist&page=1&tclass2val=0>
- ダウンロード: <https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040430819&fileKind=0> (.xlsx)

## 系列の定義

- **日本人移動者**です(外国人は含みません)。
- **都道府県間**の移動だけです。同じ都道府県内の市区町村間移動は含みません。
- 移動前の住所地が不詳の者は含みません。
- 1年は1月〜12月の累計です。年はシート名で決めます(シート内の表題の年は古いまま残っていることがあり、2012年のシートの表題は「令和5年」のままです)。
- 行が移動前、列が移動後の住所地です。

## od.json の形式

```
{ "series": "日本人移動者", "unit": "人",
  "source": { "name": ..., "url": ..., "retrieved": "YYYY-MM-DD" },
  "years": [2012, ..., 2025],
  "totals": { "2012": 2317856, ... },
  "matrices": { "2012": [2209個の整数], ... } }
```

`matrices` の各配列は 47×47 を行優先で並べたものです。添字 `o*47+d` が、JISコード `o+1` の都道府県から `d+1` の都道府県へ移った人数です。同じ都道府県どうしは 0 です。`totals` は各年の配列の総和です。

## 長期時系列表(xlsx)の構造

シートは年ごとに1枚(`'2012'`〜)で、行・列の添字は0始まりです。

| 位置 | 内容 |
| --- | --- |
| 2行目 | 移動後の住所地の名称 |
| 4行目 | 移動後の住所地のJISコード(4〜50列目) |
| 6行目 | 全国の総数行(3列目が全国総数) |
| 7〜53行目 | 移動前の住所地。北海道〜沖縄県(JISコード順)。0列目がJISコード、1列目が名称 |
| 4〜50列目 | 移動後の住所地。北海道〜沖縄県 |
| 3列目 | 行ごとの総数 |
| 54行目以降・51列目以降 | 3大都市圏・大都市(使わない) |

同じ都道府県どうしのセルは `-` です。

`build_od.py` は見出し(都道府県名・JISコード)が想定どおりかを確認し、違えばエラーで止まります。e-Stat が表の形を変えた年は、ここで気づけます。

## 実行手順

```
pip install -r tools/data/requirements.txt
python3 tools/data/build_od.py     # raw/ に原本がなければ取得し、public/data/od.json を生成
python3 tools/data/verify_od.py    # 検証(すべて通れば終了コード0)
```

- `build_od.py` は `tools/data/raw/11-long.xlsx` があればそれを使います。取得し直すときは `--refresh` を付けます。
- 原本を取得すると `raw/SOURCE.txt` に取得日と取得URLが記録され、`od.json` の `source.retrieved` にはその日付が入ります。
- `verify_od.py` は、照合に使う年報(基本集計)第2表の xls と旧作品の `data.json` が `raw/` になければ取得して保存します。

### 新しい年を加えるとき

1. 一覧ページで新しい年のシートが追加されたか確認します。
2. `python3 tools/data/build_od.py --refresh` で原本を取得し直します。
3. `verify_od.py` の `PUBLISHED`(各年の公表値)に新しい年の合計を足します。公表値は統計局の公表資料で確認します。
4. 年の範囲は `verify_od.py` の `years` の検査(2012〜2025)も更新します。

## 検証の内容

`verify_od.py` は次を確かめます。

- 各年の合計が、同じシートの全国総数セル(6行目3列目)と一致する。
- 2013〜2025年の合計が公表値と一致する。
- 2014年の全セルが、旧作品(2015年)のデータ <https://structure-and-representation.com/works/prefecturalMigrants/data.json> と一致する。
- 2012年・2013年の全セルが、各年の年報(基本集計)第2表「男女，移動前の住所地別都道府県間移動者数」の日本人移動者(総数)と一致する。年報の一覧は <https://www.e-stat.go.jp/stat-search/files?page=1&layout=datalist&cycle=7&toukei=00200523&tstat=000000070001&tclass1=000001040402&tclass2val=0&year=20130&month=0> で、`year=` を年に差し替えます。
- 全年で、対角が 0、非対角が正の整数、要素数が 2209 である。
- 全年のすべてのセルが、xlsx 原本のセルと一致する(`build_od.py` とは別の読み方で確認)。

## raw/ にあるもの

| ファイル | 内容 |
| --- | --- |
| `11-long.xlsx` | 長期時系列表 第11表の原本 |
| `nenpo2012_t2.xls`, `nenpo2013_t2.xls` | 年報(基本集計)2012年・2013年の第2表。照合に使用 |
| `prefecturalMigrants-data.json` | 旧作品の2014年データ。照合に使用 |
| `SOURCE.txt` | 各ファイルの取得日・取得URL |

## 出典表記

作品やデータを公開する場所には、次のように出典と加工の旨を書きます。取得日は `od.json` の `source.retrieved` と同じ日付にします。

> 出典:「住民基本台帳人口移動報告」(総務省統計局)を加工して作成(取得日: YYYY-MM-DD)

政府統計の総合窓口(e-Stat)の利用ルールは、コンテンツを加工して使う場合に、出典とは別に加工した旨を記載することを求めています。国が作成したかのような形で公表してはいけません。詳細は <https://www.e-stat.go.jp/terms-of-use> を確認してください。
