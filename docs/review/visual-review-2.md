## 4. 賞の水準へ届かせるための改善(効果の大きい順)

重要度は次の3段階です。
- **A** 公開の前に必ず直す
- **B** 賞の水準に届かせるために直す
- **C** 余裕があれば直す

### N-1 縦画面の数値の表で、選択地域の行が崩れる(A)

- **何が起きているか**: 地域を選んで縦画面で表を開くと、先頭の要約の行(例「大阪府 160,358 142,869 +17,489」)の各セルが幅 28px に潰れます。字が1字ずつ縦に並び、下の「北海道」の行に重なります。
- **画面**: `shots-2/mi-table.jpg`、`shots-2/crop-m390-table-pinned-row.png`
- **原因(確認済み)**: `src/styles/ui-selector.css` の 233 行目、縦画面のメディアクエリの中の `.sel { display: flex; … height: 44px; padding-top: 14px; }` が、id で限定されていません。そのため、表の `tr.sel`(`table.data tr.sel`)にも当たります。計算された値を確かめると、`tr` は `display: flex`、`td` は `display: block` でした。
- **どう直すか**: `ui-selector.css` の縦画面のブロックにある `.sel`、`.sel.is-sel …` の規則を `#selector .sel` に限定します。表の側の行のクラス名を `is-current` に変えると、なお安全です(`ui/table.js` と、`ui-table.css` の 177 行目)。

### N-2 全国の斜め俯瞰で、地上と地下が「日本海側と太平洋側」に見える(B。データの誠実さ)

- **何が起きているか**: 北を上にして弧を立てると、地上の弧(北上)は列島の北西側へ、地下の弧(南下)は南東側へ投影されます。正投影では高さの手がかりが弱いため、「北上する移動は日本海側を、南下する移動は太平洋側を通る」と地理の意味に読まれるおそれがあります。破線の違いは、全国表示の密度では見分けにくいです。
- **画面**: `shots-2/d-c1-c-mid.jpg`、`shots-2/s-ink-obl.jpg`、`shots-2/crop-ink-oblique-core.png`
- **どう直すか**:
  1. 1章の第2場面(斜め)にいる間だけ、図の中に注記を2つ置く。北西側の弧の束の外縁に「地上:北上する移動」、南東側の外縁に「地下:南下する移動」を、11px、`--fg-3`、札の地で置き、長さ 24px の `--line-1` の引き出し線を付ける。位置は、`figureCloud` の点のうち、画面の上・右と下・左の方向に最も離れた点から、外側へ 16px のところ。
  2. 1章のカードの本文に、場面ごとの差し替えを入れる。第2場面では最後の文を「列島の上に立つ弧は北へ、地面の下へ垂れる弧は南へ向かう移動。」にする(`ch.0.body.step1` を文案担当が足す)。
  3. 凡例の線画(16×10px)を、地面の平行四辺形と、その上の弧/下の破線の弧にする(カメラのアイコン「斜め」と同じ造形)。

### N-3 1024px 前後で、陸地と弧が読み出しの数に重なる(A)

- **画面**: `shots-2/s-1024-c3.jpg`、`crop-1024-readout-overlap.png`(「−11,722」の「−」が北海道の陸地と弧に重なる)。
- **どう直すか**: 前回の A-3 の 3. を入れます。
  ```css
  #selector .sel::before {
    content: ""; position: absolute; z-index: -1; inset: -24px -40px -32px -64px;
    background: var(--veil);
    mask-image: linear-gradient(270deg, #000 75%, transparent),
                linear-gradient(180deg, #000 calc(100% - 32px), transparent);
    mask-composite: intersect;
  }
  ```
  あわせて、幅 1280px 未満では `figureRegion` の上端を、選択時の読み出しの下端(約 y 330)まで下げます。現在の `DESKTOP_FIGURE_TOP` は 320 ですが、1024px では読み出しが図の領域の右上に食い込んでいます。

### N-4 1024×768 で、スクロールの手がかりが本文の最終行に重なる(A)

- **画面**: `shots-2/crop-1024-scroll-hint.png`(「線より上の弧は北へ」の行に「スクロールで章が進む」が重なる)。
- **原因**: `ui-hints.css` の `.hint-scroll { bottom: 222px }` が固定の値です。高さが低い画面では、カードの下端が変わるのに追従しません。
- **どう直すか**: `bottom: calc(var(--card-bottom) - 26px)` にして、カードの下端の直下に置きます。より確実なのは、1章のカードの末尾(`.chapter-card` の中)に置くことです。

### N-5 墨のテーマで、本州の芯が白く飽和する(B)

- **画面**: `shots-2/crop-ink-oblique-core.png`、`shots-2/s-ink-c2.jpg`
- **何が起きているか**: 東京〜大阪の間が白い塊になり、粒子の数(量)が読めません。量の多い区間ほど飽和して差がつかないので、量の読み取りが上で頭打ちになります。
- **どう直すか**: 墨のテーマの値を下げます。
  - `--gl-particle` を .50 から .38、`--gl-particle-sel` を .65 から .52 にする。
  - `--gl-arc-all` を .085 から .06 にする。
  - 粒子の数は変わらないので、量の表現の約束は守られます。
  - 紙のテーマと並べて、芯の濃さの段階が4段以上見分けられることを撮影で確かめてください。

### N-6 360×640 で、カードの上端が字の途中で切れる(B)

- **画面**: `shots-2/q360-400.jpg`(見出しの末尾の「えた」だけが残る)、`shots-2/p-360-c2.jpg`
- **何が起きているか**: 縦画面のカードは `position: fixed; overflow: hidden` の窓で、中の文がスクロールに合わせて上へ流れます。下端はぼかしてありますが、上端にはぼかしがありません。
- **どう直すか**: カードの窓に上下のマスクを付けます。
  ```css
  mask-image: linear-gradient(180deg, transparent 0, #000 20px, #000 calc(100% - 24px), transparent);
  ```
  あわせて、360×640 では補足(`.note`)を隠してください。

### N-7 真横から斜めへの遷移の途中で、ラベルが宙に浮く。遷移が長い(B)

- **画面**: `shots-2/dm-f1100.jpg`(ラベルが索引の位置に残ったまま薄くなる)、`dm-f1400.jpg`(縦書きのラベルが、点と離れて図の下に散る)、`dm-f2700.jpg`(図が斜めに伸びる長い時間)、`dm-f3600.jpg`(着地)
- **何が起きているか**: 遷移は約 3 秒かかります。そのうち約 1.5 秒は、レンズ形の図が傾いて伸びる「どちらでもない」状態です。
- **どう直すか**:
  1. ラベルを、索引の位置から点の東 7px の位置まで、morph の進みに合わせて補間する。縦書きから横書きへの切り替えは morph が 0.3 のときにし、そこで不透明度を 0.2 まで一度落とす。点から 40px 以上離れたラベルは出さない。
  2. 遷移を2つの段に分ける。最初の 0.8 秒で、真横のまま morph を 0 から 1 にする(点が地理の並びへ動き、弧の高さが変わる)。続く 1.0 秒で、カメラを起こす(方位と仰角)。全体を 2.0 秒以内に収めると、傾いた中間の状態がなくなります。`cameraRig.js` の補間で、`morph` と、`azimuth` / `elevation` の緩急を別にします。

### N-8 5章の場面が、本文の例を指さない(B。物語)

- **画面**: `shots-2/d-c5-a-start.jpg`(大阪府を選んでいるが、兵庫への弧が強調されない)、`d-c5-b-step2.jpg`(千葉県 2012年)
- **どう直すか**:
  1. 場面に `hover` を足す。大阪府の場面では `{ type: 'arc', o: 26, d: 27 }`(大阪→兵庫)、千葉県の2つの場面では `{ type: 'arc', o: 11, d: 12 }`(千葉→東京)。朱で強調され、ツールチップの代わりに、弧の脇に人数の札を出す。朱をホバー中の弧に使うのは指針の範囲内です。
  2. 5章のカードの文を場面ごとに分ける。`ch.4.step0`〜`ch.4.step3` を文案担当が足し、カードの本文を場面で入れ替える。各 1〜2 文です。たとえば「大阪府から兵庫県へは、14年間毎年2万6千〜2万7千人台。」
  3. 1章の第2場面も、N-2 の 2. と同じ仕組みで本文を差し替える。

### N-9 縦画面の斜め俯瞰で、北海道の陸地が右端で切れる(C)

- **画面**: `shots-2/m-c2-b-step2.jpg`、`p-390-obl-ink.jpg`
