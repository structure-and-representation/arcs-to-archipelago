# 視覚デザイン仕様(確定)

「弧が列島になる / Arcs Become an Archipelago」の UI 部品の仕様です。実装担当は、この文書、`tokens.css`、`mock/`、`shots/` を見て部品を作ります。技術的な前提(state のキー、モジュールの約束、座標系)は `docs/technical-design.md` に従います。

- 色と文字と時間の値は、すべて `tokens.css` のカスタムプロパティから読みます。この文書の数値は説明のためのもので、CSS に直接書くのは寸法(px)だけです。
- 文中の「モック」は `mock/mock.html`(画面)と `mock/components.html`(部品の状態)、「画像」は `shots/` の PNG です。
- モックの数値のうち、2014年の総数 2,259,688人と、東京圏の転入 468,576・転出 359,168・差引 +109,408 は試作のデータから計算した値です。年の折れ線の値、表とツールチップの数字は仮の値です。章の文言も仮で、文案担当の確定稿に差し替えます。

## 1. 指針と決めごと

**指針は「一枚の刷り物、朱は問いに答えるときだけ」です。**

統計年鑑や地図帳の一頁のように、画面のすべてを紙に刷られたものとして扱います。全国表示の画面には朱が一点もありません。読者が地域を選んだとき、つまり問いを立てたときに初めて、朱が一点だけ現れます。

### 使わないもの

- 影(box-shadow による浮き上がり)、角丸のカード、グラデーションの面、半透明のぼかし(backdrop-filter)。
- パネルの輪郭線。文は紙の上にそのまま置きます。図に重なるところだけ、縁をぼかした紙色の下敷き(`--veil`)を敷きます。例外は、ポップオーバー、ツールチップ、表のダイアログで、これらは `--line-2` のヘアラインの枠を持ちます。
- 飾りのアイコン。アイコンはカメラの3つの定位置と、選択の開閉の小さな山形(chevron)だけです。
- 600 より太い字、数え上げの演出、パララックス。

### 決めごと

- 構造は、罫線(ヘアライン)と、字の濃さの3段階(`--fg-1`、`--fg-2`、`--fg-3`)だけで作ります。
- 「選択中」は、墨の文字(`--fg-1`)と、中央に置いた幅20px・高さ1.5pxの下線で示します。年、カメラ、トグルで共通です。
- 朱(`--accent`)を使うのは次の場所だけです。
  - 選択中の地域: キャンバスの点、ラベル、読み出しの見出し、選択の一覧の選択中の項目、表の選択中の行の名前。
  - ホバー中の弧: キャンバスの弧と粒子、ツールチップの短い線。
- 数値は明朝(Source Serif 4)の等幅数字で組み、統計書の数表のように見せます。UI の文字は IBM Plex Sans JP です。
- 真横の都道府県名は、レンズの下に縦書きで並べた索引にします(縦画面ではレンズの右に横書き)。

## 2. 色

`tokens.css` が正です。テーマは `<html data-theme="ink">` で切り替えます(state の `theme` が `'paper'` のときは属性なし、`'ink'` のときに付ける)。

### 原色

| トークン | ライト(paper) | ダーク(ink) |
|---|---|---|
| 地 `--bg` | 紙 `#F3F0E8` | 墨 `#1C1B18` |
| 文字・線の元 `--fg-rgb` | 墨 `28 27 24` | 紙 `243 240 232` |
| 朱 `--accent` | `#C23B22` | `#E5603F` |

ダークの朱は、墨の地で AA を満たすように明度だけを上げた同じ朱です。

### 段階とコントラスト比

コントラスト比は、地(`--bg`)の上に不透明度で重ねた色で計算した値です。

| トークン | 用途 | ライト | ダーク |
|---|---|---|---|
| `--fg-1` | 見出し、本文、数値、選択中 | 1.0 → 15.1:1 | .92 → 12.9:1 |
| `--fg-2` | 補助の文、ボタンの通常 | .74 → 6.8:1 | .70 → 8.0:1 |
| `--fg-3` | 注記、ラベル、トグルの通常(これより薄い文字は使わない) | .64 → 4.9:1 | .58 → 5.9:1 |
| `--fg-off` | 無効の状態だけ(WCAG 対象外) | .38 → 2.3:1 | .34 → 2.9:1 |
| `--accent` | 朱の文字 | 4.68:1 | 4.98:1 |
| `--line-1` | 折れ線、強い罫、表の見出しの下 | .32 | .30 |
| `--line-2` | 罫線(ヘアライン)、枠 | .16 | .15 |
| `--line-3` | 補助の罫、表の行の区切り | .08 | .07 |
| `--veil` | 図の上の下敷き | 地 .88 | 地 .88 |
| `--veil-solid` | ポップオーバー、ツールチップ、表、縦画面のドック | 地 .97 | 地 .97 |
| `--halo` | ラベルの縁取り | 地 .92 | 地 .92 |

- 下敷きの上(弧の網 15% の上に `--veil`)でも、`--fg-3` はライト 4.75:1、ダーク 5.6:1 で AA を満たします。
- 弧の網の上に直接置いた朱は 3.5:1 程度まで落ちます。弧に重なりうるラベルには、必ず縁取り(5.9 節)を付けます。
- フォーカスの輪郭は `--focus`(= `--fg-1`)で、非テキストの 3:1 を満たします。

### 紙の質感

`body` の疑似要素2枚で作ります。どちらも `position: fixed; inset: 0; pointer-events: none; background: var(--fg-1)` に、`mask-image` で質感を掛けます。色は fg の不透明度だけで、新しい色は作りません。画像ファイルは使いません(実装は `base.css`、`ui/paper.js`)。

| 層 | マスク | 不透明度(ライト / ダーク) |
|---|---|---|
| 繊維(`::before`) | 楮の繊維と塵(`ui/paper.js` が起動時に canvas で1回だけ描く 560px のタイル。端をまたぐ繊維を反対側にも描くので、つなぎ目が出ない)と、細かな地のノイズ(feTurbulence .85、256px) | `--grain` .065 / .05 |
| むら(`::after`) | 漉きむら(feTurbulence .0032、4 octaves、1400px)と、雲肌(.022×.034 のやや横長の粒、480px) | `--mottle` .04 / .03 |

- 暗い地では、同じ強さのむらが紙の地より目立つので、ダークの値を小さくしています。
- 繊維とむらが重なる最悪の画素でも、`--fg-3` のコントラスト比はライトで 4.5:1、ダークで 5.2:1 を下回りません。
- 陸地の面には、地図に固定した淡墨のむら(濃さ ±35%、径 160km)と、海岸線に沿った幅 5px のにじみの帯を重ねます(`scene/ground.js` の `LAND_INK`)。県境の、紙の色で抜いた線はそのまま残します。
- 選択中の都道府県の点は、縁がわずかにゆらぎ、面にかすれのある朱の印にします(`scene/renderer.js` の `SEAL`)。読み出しの見出しにも、朱肉のかすれのマスクを掛けます。

---|---|---|
| 繊維 | baseFrequency .85、3 octaves、256px のタイル | `--grain` .055 / .045 |
| むら | baseFrequency .006、3 octaves、900px のタイル | `--mottle` .02 / .03 |

## 3. 文字と Webフォント

### 書体

| トークン | 並び | 使う場所 |
|---|---|---|
| `--font-serif` | `"Source Serif 4", "Noto Serif JP", "Hiragino Mincho ProN", "Yu Mincho", serif` | 作品名、章の見出しと本文、読み出しの数値、ツールチップの人数 |
| `--font-sans` | `"IBM Plex Sans JP", "Hiragino Sans", "Yu Gothic UI", "Noto Sans JP", sans-serif` | UI のすべて、ラベル、注記、表 |

明朝は欧文の書体を先に置くため、和文の中の英数字は Source Serif 4 で組まれます(欧文混植)。

### サイズ・行間・字間

| トークン | 値 | 使う場所 |
|---|---|---|
| `--fs-label` | 11px | 都道府県名、年の数字、目次、章番号 |
| `--fs-caption` | 12px | 注記、凡例、表、トグル、ツールチップ |
| `--fs-ui` | 13px | ボタン、選択、読み出しの「全国」 |
| `--fs-body` | 15px | 章の本文(和) |
| `--fs-body-en` | 16px | 章の本文(欧) |
| `--fs-h2` | 22px | 章の見出し(英語は 24px) |
| `--fs-num` | 28px | 読み出しの大きな数(総数、差引) |
| `--fs-title` | 17px | 作品名(縦画面は 15px) |

- 和文本文: 行間 1.95、字間 .04em、両端揃え(`text-align: justify; text-justify: inter-character`)、`line-break: strict`。
- 欧文本文: 行間 1.6、字間 0、左揃え、`hyphens: auto`。
- UI: 行間 1.5、字間 .02em。章番号など英数の小見出しは字間 .12em。
- 縦画面: 章の見出し 19px、和文本文 14.5px で行間 1.85、欧文本文 15px で行間 1.55。都道府県名の索引 10.5px。
- 明朝の見出しは 600、本文は 400。ゴシックは 400 と、強調に 500。

### 数字

- 表、読み出し、年、ツールチップの数はすべて `font-variant-numeric: tabular-nums lining-nums` で組みます。
- 桁区切りはカンマです(日本語でも `1,234`)。
- 差引には必ず符号を付けます。正は `+`、負は U+2212 の `−` です(ハイフンではない)。
- 縦画面のドックの要約だけは略します。日本語は「46.9万」(1万未満は「9,870」のまま)、英語は「469k」です。正確な値は表で読めます。
- 単位「人」はゴシックの 12px、`--fg-3` で数の右に添えます。英語では読み出しの単位を省きます。

### Webフォントの読み込み

`index.html` の `<head>` に、次の順で書きます。

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<!-- 作品名だけの部分集合(数KB)。作品名が差し替わったら text= も変える -->
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Serif+JP:wght@600&text=%E5%BC%A7%E3%81%8C%E5%88%97%E5%B3%B6%E3%81%AB%E3%81%AA%E3%82%8B&display=block">
<!-- 本体。描画を止めない -->
<link rel="stylesheet" media="print" onload="this.media='all'"
  href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans+JP:wght@400;500&family=Noto+Serif+JP:wght@400;600&family=Source+Serif+4:opsz,wght@8..60,400;8..60,600&display=swap">
<noscript><link rel="stylesheet" href="(上と同じ URL)"></noscript>
```

- 日本語の書体は Google Fonts が unicode-range で細かく分けて配信するので、画面で使う字の分だけが届きます。
- 入れ替わるときのずれを抑えるため、フォールバックに `size-adjust` を指定した `@font-face`(`local("Hiragino Mincho ProN")`、`local("Yu Mincho")` など)を置くことを推奨します。値は実装時に測って決めます。
- キャンバスはフォントに依存しません。ラベルの配置は、`document.fonts.ready` が解決した後にもう一度計算し直します。
- 撮影(`still=1`)では `document.fonts.ready` を待ってから撮ります。

## 4. 画面の構成と重なり順

### 重なり順(下から)

| 層 | 中身 | 位置 |
|---|---|---|
| 0 | 紙の質感(`body` の疑似要素) | fixed |
| 1 | キャンバス(透明)。弧、粒子、地面、境界線、都道府県の点 | fixed、画面いっぱい |
| 2 | ラベルの層(都道府県名) | fixed、`pointer-events: none`(ラベル自体は `auto`) |
| 3 | 章の本文 | 通常のページスクロール |
| 4 | 固定の UI: 上の帯、凡例と注記、読み出し、年の切り替え、カメラ、縦画面のドック | fixed |
| 5 | ポップオーバー、ツールチップ、表のダイアログ | fixed |

章の本文は、凡例と上の帯の下に潜って消えます。固定の UI のうち、上の帯と凡例の領域には紙色の下敷き(5.1 節、5.8 節)を敷き、その上に流れてきた本文を隠します。

### デスクトップ(基準 1440×900)

左右の余白は 40px です。画像は `shots/desktop-*.png` を見てください。

| 領域 | 位置 |
|---|---|
| 上の帯 | 上端から高さ 72px。左に作品名と副題、右に操作 |
| 目次 | 左 40px、上 96px、幅 300px |
| 章の本文 | 左 40px、幅 344px。ページスクロールで流れる |
| 図の領域 | x 424〜1400。カメラの中心をこの領域の中心へずらす(`setViewOffset` などで) |
| 読み出し | 右 40px、上 96px、幅 300px、右揃え |
| 凡例と注記 | 左 40px、下 36px、幅 344px |
| 年の切り替え | 左 424px、下 36px、幅 658px |
| カメラ | 右 40px、下 36px |

- 真横の定位置では、一直線の並びが図の領域の幅いっぱいに近く(モックでは 910px)なるように拡大率を決めます。縦の中心は y≈440 で、レンズの下に索引ラベルが入る余地を残します。
- 斜め俯瞰では、列島の全体が x 424〜1400、y 300〜640 程度に収まるようにします。読み出しの下端(y≈300)と重ならないようにします。
- 1440 と異なる幅では、左の柱(384px まで)と右の読み出し(300px)の幅は固定し、図の領域だけが伸び縮みします。幅 1024px 未満は縦画面の構成に切り替えることを推奨します(境の値は実装で確かめる)。

### 縦画面(基準 390×844)

左右の余白は 16px です。画像は `shots/mobile-*.png` を見てください。

| 領域 | 位置 |
|---|---|
| 上の帯 | 上端から高さ 52px |
| 章の位置 | 上 50px、左 16px。5本の短い線と章名 |
| 図の向きの注記 | 上 76px、左 16px(5.8 節) |
| 図 | 一直線の並びが y 72〜678 に収まるようにする。北(北海道)が上 |
| 都道府県名の索引(真横) | 並びの線から右へ 98px の位置に左揃え |
| ドック | 下端に固定、高さ約 150px、地は `--veil-solid`、上にヘアライン |
| 章の本文 | 左右 16px のカードとして図の上を流れ、ドックの下に潜る |

- 真横の定位置では、カメラを時計回りに90度回します。地上(北へ向かう流れ)の弧は画面の右側に、地下(南へ向かう流れ)は左側に出ます。
- 斜め俯瞰でも同じく時計回りに90度回し、北海道を上にします。
- 真上は技術設計どおり北を上にします(回転はそれ自体で決まる)。
- ドックの高さが決まったら、図の下端がドックの上端より 12px 以上上になるように、図の拡大率を決めます。画面の高さに応じて拡大率を計算し直します。

## 5. 部品

### 共通の状態

| 状態 | 見え方 |
|---|---|
| 通常 | トグル類は `--fg-3`、ボタン類は `--fg-2` |
| ホバー | `--fg-1`(時間 `--dur-1`) |
| フォーカス | `:focus-visible` のときだけ、`outline: 1.5px solid var(--focus); outline-offset: 3px`。マウスで押したときには出さない |
| 選択中 | `--fg-1` と、中央に幅20px(縦画面は14px)・高さ1.5pxの下線(`--fg-1`)。`aria-pressed="true"` または `aria-current` |
| 無効 | `--fg-off`、下線なし、`cursor: default`、`aria-disabled="true"` |

押せる範囲は、デスクトップで最低 32×32px、縦画面で最低 44×44px です(見た目の文字が小さくても、余白で範囲を広げる)。

部品の状態の見本は `mock/components.html`(画像 `shots/components.png`、左がライト、右がダーク)にあります。

### 5.1 上の帯(`ui/controls.js` の一部)

**デスクトップ**(画像 `desktop-side-light.png` の上端)

- 高さ 72px、左右の余白 40px。項目は縦方向の中央に揃えます。
- 左: 作品名「弧が列島になる」(英語は「Arcs Become an Archipelago」)。明朝 600、17px、字間 .08em(英語は .01em)。その右に 14px 空けて副題「都道府県間の人口移動 2012–2025」(英語は「Migration between Japan’s prefectures, 2012–2025」)をゴシック 12px、`--fg-3` で、ベースラインを揃えて置きます。
- 右: 間隔 22px で、次の3つを並べます。
  1. 「数値の表」(英語は「Data table」): `--fg-2`、下に `--line-2` の 1px の線。表のダイアログ(5.6 節)を開きます。
  2. 言語のトグル「日本語 / EN」(5.7 節)。
  3. テーマのトグル「紙 / 墨」(英語は「Paper / Ink」)(5.7 節)。
- 作品名は `<h1>` です。
- 上の帯の領域(高さ 72px)には `--veil` の下敷きを敷き、下端の 24px で透明へぼかします。流れてきた章の本文がここで消えます。

**縦画面**(画像 `mobile-side-light.png` の上端)

- 高さ 52px、左右の余白 16px。
- 左: 作品名だけ(15px)。副題は出しません。
- 右: 「表」「EN」「墨」の3つの文字のボタン(英語では「Table」「日本語」「Dark」)。ゴシック 12px、`--fg-2`、それぞれ 36×44px 以上。言語とテーマは、押すと反対側へ切り替わる1つのボタンで、表示する文字は切り替え先の名前です。
- ARIA: 言語のボタンは `aria-label="English に切り替え"` のように、何が起きるかを書きます。

### 5.2 章の本文と目次(`ui/chapters.js`)

**目次(デスクトップ)**(画像 `desktop-side-light.png` の左上)

- 左 40px、上 96px。11px、字間 .06em、行の間 3px。
- 各行は「01」(等幅数字、幅 22px)と章名です。章名は「全国」「東京一極」「大阪圏」「名古屋圏」「自由探索」、英語は「Japan」「Tokyo」「Osaka」「Nagoya」「Explore」です。
- 現在の章は `--fg-1`、ほかは `--fg-3`。ホバーで `--fg-1`。
- 各行はその章の先頭へスクロールするリンクです(`<nav aria-label="章"><ol>`、現在の章に `aria-current="step"`)。
- 動きを減らす設定のときは `scroll-behavior: auto`、そうでなければ `smooth` にします。

**章の位置(縦画面)**(画像 `mobile-side-light.png`)

- 上 50px、左 16px。幅 14px・高さ 1.5px の短い線を 4px 間隔で5本並べ、現在の章を `--fg-1`、ほかを `--line-2` にします。右に 6px 空けて「01 全国」を 10.5px、`--fg-3` で出します。
- 押せる範囲はなく、表示だけです(`aria-hidden="true"`)。章の移動はスクロールで行います。

**章の本文**

- 各章は `<section>` で、高さは画面の高さの 100% 以上にします(最後の「自由探索」は短くてよい)。章の境をまたいだときに state の `chapter` を変えます(IntersectionObserver で、本文の塊が画面の高さの中央を越えたとき)。
- 中身は次の3つです。
  1. 章番号「01 — 全国」: ゴシック 11px、字間 .12em、`--fg-3`、下に 14px。

- 出典の注記は、表のダイアログの末尾に置きます。ドックには出しません。

### 5.9 都道府県名のラベル(`ui/labels.js`)

47個のラベルを HTML の要素で作り、毎フレーム、射影した位置へ動かします(`transform: translate()` で動かし、`left` と `top` は使わない)。

**共通**

- ゴシック 11px(縦画面は 10.5px)、行間 1、字間 .04em、`white-space: nowrap`。名前は「都」「府」「県」を省いた短い名前(「東京」「神奈川」、英語は「Tokyo」)。
- 色:

| クラス | 色 | 使う場面 |
|---|---|---|
| 通常 | `--fg-3` | 索引、端点、人口の多い県 |
| `em` | `--fg-1` | 章で扱う県、ホバー中の県 |
| `partner` | `--fg-2` | 選択地域の相手先 |
| `sel` | `--accent`、500 | 選択中の都道府県 |
| `sel group` | `--accent`、500、13px、字間 .08em | 選択中の圏の名前(「東京圏」) |

- 縁取り: 弧に重なりうるラベル(斜め俯瞰と真上のとき)には、`--halo` の多重の `text-shadow`(0 0 1px、2px、2px、3px、4px、6px)を付けます。真横の索引は弧に重ならないので縁取りを付けません(暗い地で縁取りが四角い影に見えるため)。
- 出入り: 不透明度だけを `--dur-1` で変えます。
- 都道府県の点はキャンバスに描きます(墨の直径 3px、選択中は朱の直径 6px に紙色の 1.5px の輪)。ラベルは点の位置を基準にずらして置きます。

**真横(デスクトップ)**(画像 `desktop-side-light.png`)

- 47個すべてを、レンズの下に縦書きの索引として並べます。`writing-mode: vertical-rl; text-orientation: mixed`、字間 .12em(英語は .02em、英字は90度回して組まれる)。
- x は各点の x(ラベルの中心を合わせる)、y は並びの線から 132px 下(レンズの下端より 12px 程度下)にラベルの上端を揃えます。この値は拡大率に比例させます(レンズの高さ +12px)。
- 等間隔なので重なりません。間引きもしません。

**真横(縦画面)**(画像 `mobile-side-light.png`)

- 47個すべてを、並びの線から右へ 98px の位置に、左揃えの横書きで並べます(この値もレンズの幅に比例させる)。y は各点の y(ラベルの縦の中心を合わせる)。
- 画面の高さが 700px 未満のときは1つおきに出します。北海道から数えて偶数番目(0, 2, 4, …、つまり北海道、岩手、秋田…)を残し、奇数番目を隠します。ただし選択中、ホバー中、章で扱う県は常に出します。

**斜め俯瞰と真上**(画像 `desktop-tokyo-light.png`、`mobile-tokyo-light.png`)

優先度の高い順に、重ならない位置を探して置いていきます(貪欲法)。

1. ホバー中の県(常に出す。ほかのラベルを押しのける)。
2. 選択中の地域。
   - 圏を選んでいるとき: 構成県の名前は出さず、圏の名前(「東京圏」)を1つだけ、構成県の点の重心を基準に置きます。
   - 都道府県を選んでいるとき: その県の名前。
3. 選択地域の相手先の上位6県(選択地域との転入と転出の合計の多い順)。
4. 章で扱う県。
5. 端点(北海道、沖縄、鹿児島)。
6. 人口の多い順(全国表示のとき)。

- 全国表示では合計 16個まで、地域を選んでいるときは 1〜5 の分だけにします。
- 候補の位置は、点からの距離(dx, dy)で次の順に試します(dy が「中央」のときはラベルの縦の中心を点に合わせる)。
  1. 東(+7, 中央)
  2. 西(−7, 中央、ラベルの右端を合わせる)
  3. 北(0, −11、ラベルの中心を合わせる)
  4. 南(0, +10)
  5. 北西(−12, −14)
  6. 北東(+12, −14)
  - 圏の名前だけは、北西(−16, −20)と北東(+16, −20)を先に試します(点の集まりから離して置くため)。
- 置かない条件(どれかに当たれば次の候補へ。全部だめならそのラベルは出さない):
  - すでに置いたラベルと 3px 以内で重なる。
  - 固定の UI の領域と 6px 以内で重なる。
  - 選択中の点を覆う。
  - 画面の端から 8px 以内にはみ出す。
- 一度出たラベルは、次の計算で同じ位置が空いていればそこに残します(ヒステリシス)。ちらつきを防ぐためです。
- カメラが動いている間は、配置の計算を 100ms に1回までにします。カメラが止まったら一度計算し直します。
- 地面と境界線が入った状態での読みやすさは、実装後の視覚レビューで確かめます。引き出し線はその結果を見て決めるので、いまは作りません。

**操作と ARIA**

- ラベルは押せます(その都道府県を選ぶ)。ラベルの層の要素は `pointer-events: none` にし、各ラベルだけ `auto` にします。
- 47個のラベルは、画面に出ていないものも含めて `<button>` にし、`aria-label="東京都を選ぶ"` のように書きます。Tab で順に回ると長すぎるので、ラベルの層全体を1つの Tab の止まりにし、中は ←→(真横の並び順)または ↑↓ で移動します(roving tabindex)。フォーカス中のラベルは出していなくても出し、`em` にしてツールチップを出します。Enter で選びます。

## 7. 動き

| トークン | 時間 | 緩急 | 使う場所 |
|---|---|---|---|
| `--dur-1` | 120ms | `--ease-out` `cubic-bezier(.2, 0, 0, 1)` | ホバー、色の変化、ラベルとツールチップの出入り |
| `--dur-2` | 200ms | `--ease-out` | 選択中の下線の移動、ポップオーバーの出入り(不透明度と 4px の移動) |
| `--dur-3` | 320ms | `--ease-out` | 読み出しの数の入れ替わり(不透明度だけ) |
| `--dur-year` | 600ms | 線形 | 年の補間(`setYear(a, b, mix)`) |
| `--dur-cam` | 1600ms | `--ease-inout` `cubic-bezier(.65, 0, .35, 1)` | カメラの定位置の移動。morph と lean も同じ時間と緩急 |

- 章が変わったときのカメラと選択の変化は、スクロールの量に連動させず、章の境をまたいだときに一度だけ動かします。
- 移動中に次の指示が来たら、そのときの位置から新しい目標へ向かい直します(最初からやり直さない)。
- 読み出しの数は数え上げません。
- **動きを減らす設定**(`prefers-reduced-motion: reduce`、または state の `reducedMotion`):
  - CSS の時間はすべて 0 です(`tokens.css` で切り替わる)。
  - カメラ、morph、年、選択は即座に切り替えます。
  - 粒子は技術設計どおり、時間を 0 に固定した静止した点描にします。
  - 目次のリンクのスクロールは `scroll-behavior: auto` にします。
